# 《七王国 2 HD》简体中文汉化 · 安装与说明

适用于 **STEAM 2.10F** 与 **GOG 2.10E**（两套 exe 都已适配，同一份包通吃）

- 作者：HAOJUN0823
- 发布页：https://www.haojun0823.xyz/
- 源码：https://github.com/HaoJun0823/SevenKingdom_II_HD_CHINESE

---

## 一、包内有什么

| 路径 | 作用 | 能不能删 |
|---|---|---|
| `dsound.dll` | ASI 加载器，负责加载 `scripts\*.asi`（游戏目录本来就有同名文件，包内附上便于覆盖修复） | 删了中文就没了 |
| `scripts\sk2_zh.asi` | 汉化插件本体：中文字形渲染 + 数据表改写 | 删了中文就没了 |
| `update\` | 中文资源覆盖目录（文本 / 战役 / 场景 / 配置），游戏原生的覆盖机制会优先读它 | 删了中文就没了 |
| `update\render.ini` | 插件配置：**简繁切换**、配色、诊断开关 | 可改，别乱删 |
| `LICENSE`、`LICENSES\` | 许可证与第三方组件声明 | 建议留着 |

**不含游戏本体**：没有 exe、没有 `.idx`/`.set` 原档、没有音乐视频。你仍然需要自己拥有游戏。

## 二、安装（Steam / GOG 都是解压即装）

1. **先备份**（30 秒，出事能立刻还原）
   把游戏目录里的 `dsound.dll`（如果有）改名成 `dsound.dll.bak`；
   `scripts\`、`update\` 两个目录如果已经存在，先整目录复制到别处。

2. **解压覆盖**
   把本包 **全部内容** 解到游戏根目录，让它和 `7K2.exe` 处于同一层。
   解完目录应该长这样：

   ```
   <游戏目录>\7K2.exe
   <游戏目录>\dsound.dll          ← 本包提供
   <游戏目录>\scripts\sk2_zh.asi  ← 本包提供
   <游戏目录>\update\render.ini   ← 本包提供
   <游戏目录>\update\Resource\STD.SET
   <游戏目录>\update\Campaign\east.evt
   ```

3. **启动游戏**
   第一次进游戏后 **等 30 秒以上**：加载器是延迟加载的，插件大约在启动
   25~30 秒后才挂上。别在这之前就断定「没生效」。

**Steam 版额外注意**：如果 Steam 校验过游戏文件、把 `dsound.dll` 换回官方版本，
中文会消失 —— 重新把本包的 `dsound.dll` 覆盖回去即可；也可以在 Steam 里把该文件
设为只读，或关掉「验证游戏文件完整性」后的自动修复。

**GOG 版额外注意**：GOG Galaxy 的「修复/验证」同样可能覆盖 `dsound.dll`，
处理方式同上。

---

## 三、确认装好了

打开 `<游戏目录>\update\sk2_zh.log`，能看到这几行就是成功了：

```
[i] render.ini: lang=... -> 简体
[i] 字形语言: 简体（13/16/24px 三档 + 补充表双池已就绪）
```

游戏内：主菜单、建筑名、科技描述、兵种名、战役文本都应该是中文。
日志里如果出现 `签名未命中` 之类的行，说明游戏版本和本包不匹配，请反馈。

## 四、简繁切换（不用重装、不用换资源）

改 `update\render.ini` 里的一行，存盘，重启游戏：

```ini
lang=simp    ; 简体
lang=trad    ; 繁体
```

也接受 `lang=chs` / `lang=cht` / `lang=hans` / `lang=hant` /
`lang=simplified` / `lang=traditional` / `lang=1` / `lang=0`。
旧写法 `chslang=1`（简）/ `chslang=0`（繁）仍然兼容，两者同时存在时以 `lang=` 为准。

- 不写 `lang=` 也不写 `chslang=` 时，**默认繁体**（历史行为，本包已显式写成 `lang=simp`）。
- 切换只换「字形池」，不动任何资源文件，所以**不需要重新安装**。
- 13 / 16 / 24 三档字号 + 补充表各有一整套简、繁字形，1121 个简繁异形字全部覆盖，
  不会再出现旧版那种「一部分字是繁体、一部分是简体」的混合画面。
- 简体/繁体指的是**显示字形**；译文本身是简体中文用词，繁体模式下同样按繁体字形显示。

## 五、更新 / 回滚 / 卸载

- **更新到新版本**：直接用新包覆盖解压，`update\render.ini` 里你改过的
  `lang=` 会被覆盖回默认，需要的话改回来。
- **回滚插件**：把新包解压前备份的 `scripts\sk2_zh.asi` 放回去即可。
  字形池是纯数据（在 asi 里），不会单独出问题。
- **彻底卸载**：删掉 `scripts\` 和 `update\`，再把 `dsound.dll.bak` 改回
  `dsound.dll`（当初没有这个文件就删掉 `dsound.dll`）。游戏即回到英文原版，
  存档不受影响（存档在 `Profile\`）。

## 六、常见问题

**1. 进游戏还是英文？**
先确认三件事：`dsound.dll` 在游戏根目录；`scripts\sk2_zh.asi` 在；`update\render.ini` 在。
再看 `update\sk2_zh.log` 有没有生成 —— 没有日志 = 插件根本没被加载（大概率 `dsound.dll` 被换回官方版）。

**2. 中文显示成方块 / 乱码？**
检查 `update\Resource\STD.SET`、`update\Campaign\*.evt` 是不是被别的版本覆盖过
（解压顺序错了会把新资源盖回旧资源）。整包重解一遍最省事。

**3. 卡死、未响应、花屏**
这个游戏**原版就有这些问题**，英文原版一样。已知相关因素：

- 快速移动鼠标、连点按钮可能导致卡死；等一会儿可能恢复，也可能彻底卡死。
- G-SYNC / FreeSync 等可变刷新率技术可能导致卡屏，关掉试试。
- 系统较新时，右击 `7K2.exe` → 属性 → 兼容性 → 勾选「以兼容模式运行（Windows 7 或更早）」
  和「以管理员身份运行」。
- 全屏独占 DirectDraw 与桌面合成器偶发冲突，可以换成窗口模式。

想确认「卡死是不是汉化造成的」：把 `update\render.ini` 里的 `# safe = 1`
改成 `safe=1`（去掉 `#`、去掉空格），重启游戏。插件会关闭全部自绘，
画面回到英文原版；如果这样还是卡，那和汉化无关。

**4. 日志文件越来越大？**
插件自带两道闸：每秒最多 200 行、累计 8MB 后自动静音，不会把磁盘写爆。
排查完可以把 `debug=0` 关掉。

**5. 汉化本身的小毛病（已知）**
- 「游戏持续时间：分钟」这里没有时间 —— 游戏自身的显示问题，翻译是对的。
- 少数英文人名会被吞掉末尾一两个字符。
- 玩家 ID 建议只用 6 个字母或数字，超过 8 个容易出怪问题。
